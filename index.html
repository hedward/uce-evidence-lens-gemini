The workflow

A public record. A clearer explanation.

01

Identify the record

Provide a public CbyUCE record hash or verification URL, or an Arweave manifest reference.

02

Inspect the evidence

The UCE service runs supported checks. Gemini explains returned results and preserves their limits.

03

Request a snapshot

Ask for a fresh unsigned inspection report bound to that record. Each report preserves its check time and coverage.

Integrity is one part of the picture.

Checks do not establish identity, authorship, ownership, rights, consent, or a creation date. An unsigned report is not a UCE Certificate or a new permanent record.

Direct installation

Connect the app. Add the skill.

Start in the Gemini web app. This preview was tested in Spark; you need access to custom connected apps, skills, and the relevant Google features.

Check your access first. Google's custom apps currently require a personal account, age 18+, US location, English, and Keep Activity enabled. Spark may require a subscription. Review Google's current requirements and your privacy choices.

  1. Connect UCE Evidence Lens

    Open Settings → Connected Apps, sometimes under Personal Intelligence. Add this URL under Custom apps or Custom apps for Spark:

    https://uce-evidence-lens-claude-zptt2ggs7a-uc.a.run.app/mcp

    This existing service is shared with our Claude integration; its hostname retains claude. It requires no credentials.

    Review the connection and confirm both tools: inspect_uce_record and get_uce_inspection_report.

  2. Upload the interpretation skill

    Download the ZIP below. In Settings → Skills → Upload, select it, review the instructions, and create inspect-uce-evidence.

    Download skill ZIP ↓SHA-256 checksum

    Four text files: instructions, evidence boundaries, license, and notices. Read the skill source.

  3. Try an explicit public record

    Start a Spark task. Select UCE Evidence Lens with @ and inspect-uce-evidence with /. Then use this public example:

    Inspect this public UCE record:
d16afbafda0ef0bf1be29d4f89e8629fc2aa0eae55da30103aeb5e6a59abd9a5
Explain each check and what remains unsupported or incomplete.

    Look for an actual tool action and returned results. Ask separately for an unsigned inspection report using the same explicit reference.

Release status

A public preview, with a defined scope.

Verified in our test

Connection, inspection, and reports

In our October 3, 2026 Gemini web test, the connector exposed both tools. Spark completed an inspection and a fresh unsigned report, each after one retry.

The revised skill also asked for a missing reference in ordinary chat without choosing a record or calling a verification tool.

Still being evaluated

Reliability and host features

Spark also produced blank or failed turns, including on a no-tools control. The cause is not established.

Native report downloads, corrected direct-link rendering, ordinary-chat tools, and mobile workflows are unverified. A downloadable report attachment is not promised.

If a turn is blank, refresh once and make one explicit retry. If it is still blank, stop and contact support or use the Evidence Lens browser. A missing response does not mean the record failed a check.

This direct-install release has not been submitted to or listed in a Google app catalog. Read the release notes.

Built for public evidence
