# Support

Contact [support@universalcreationevidence.com](mailto:support@universalcreationevidence.com)
for installation, inspection, privacy, or security questions. The operator is
5 Race Street LLC, doing business as Copyright by UCE and CbyUCE.

For troubleshooting, include the release version, approximate time and timezone,
Gemini surface (Spark or chat), whether a UCE tool action appeared, and the exact
error or status. Include a public record reference only if you are comfortable
sharing it. Remove account details from screenshots. Never send an original
work, credential, or private manifest. Report security issues privately by email.

| Symptom | Next step |
| --- | --- |
| No custom-app or skill setting | Check Google's eligibility and rollout requirements linked in the setup guide. The package cannot enable unavailable Google features. |
| Skill installed but tools missing | Connect the MCP app separately. In the tested account, tools appear in Spark's `@` picker. |
| OAuth or API key requested | Check the exact endpoint; this service requires neither. Stop and contact support if it persists. |
| Blank or failed turn | Refresh once, then make one explicit retry with the same public reference. Stop if it remains blank. Do not infer a failed evidence check. |
| Partial, unavailable, unsupported, or retryable result | Read individual checks and coverage. A public-source outage is not evidence of tampering. |
| Source link opens Google Search | Request the exact returned URL as copyable text. Direct-link rendering remains unverified in the preview. |
| No report attachment | Native file download is unverified. Use the conversation's report results or the Evidence Lens browser; do not treat a prose summary as the complete JSON report. |
| Asked whether a record proves ownership | Integrity checks do not establish ownership or other recorded assertions. |

Use the [Evidence Lens browser](https://uceevidencelens.com/) if Gemini is
unavailable or you want the existing local-file comparison workflow.
